# Blog guide

This website is built with [Quarto](https://quarto.org/). The public blog page is generated from the source files in `posts/`.

## Create a new post

1. Copy `POST_TEMPLATE.qmd` to a new folder, for example:

   ```text
   posts/2026-09-my-new-post/index.qmd
   ```

2. Edit the YAML block at the top of the file:

   ```yaml
   ---
   title: "My new post"
   description: "A short sentence shown in the blog listing."
   date: 2026-09-20
   categories:
     - research
   ---
   ```

   Use an ISO date (`YYYY-MM-DD`). The blog is sorted from newest to oldest. Categories are optional, but they make the blog easier to browse.

3. Write the article below the second `---` using Markdown. Useful examples:

   ```markdown
   **Bold text**, *italic text*, [a link](https://example.org)

   - A list item
   - Another list item

   $$
   f(x) = x^2
   $$
   ```

4. Preview the website locally:

   ```bash
   quarto preview
   ```

   Open the local address shown by Quarto and check the Blog page, the article, links, equations, and any images.

5. Rebuild the generated website:

   ```bash
   quarto render
   ```

   This updates the HTML files, the blog RSS feed (`blog.xml`), the search index, and the other generated site files.

6. Publish the changes to GitHub:

   ```bash
   git status
   git add BLOG_GUIDE.md POST_TEMPLATE.qmd posts/2026-09-my-new-post/index.qmd
   git commit -m "Add blog post: my new post"
   git push origin main
   ```

   Replace the example path and commit message with the real post. GitHub Pages will publish the pushed files from this repository.

## Add images

Put an image in `images/` and refer to it from a post. From a post in `posts/2026-09-my-new-post/`, use a path such as:

```markdown
![A short description](../../images/my-figure.png)
```

Keep filenames simple: lowercase letters, numbers, hyphens, and a file extension.

## Important details

- Do not put the reusable template inside `posts/`: Quarto would treat it as a real article.
- Keep the source post (`.qmd`) under version control. The `.html` files are generated by `quarto render` and are also copied to the repository by this site’s configuration.
- The shared settings in `posts/_metadata.yml` automatically add the author name and table of contents to posts.
- To edit or remove a post, change or delete its source folder, then run `quarto render` and review the generated changes before committing.
